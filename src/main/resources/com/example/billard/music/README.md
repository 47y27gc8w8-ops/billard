## Changes made

The licence asks you to say what you changed. Each track was:

- trimmed to remove the silence at its start and end, with a 0.8 s fade-out added;
- set to the same loudness (-20 LUFS) so no track is suddenly louder than another, with a gentle peak limiter
  where the gain would have clipped (Cool Vibes, Bossa Antigua);
- re-encoded as 160 kbit/s MP3 with the metadata removed.
